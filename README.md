# Web 音频编辑器

基于 **Web Audio API + Canvas + Web Worker** 的浏览器端音频编辑器，无需后端、无需构建步骤。

## 功能

- **波形显示**：多级峰值（min/max）金字塔，任意缩放级别都不丢峰；分声道渲染立体声；顶部总览条 + 时间标尺 + 播放头
- **编辑**：框选区域 → 裁剪（保留选区）/ 删除选区 / 线性淡入 / 线性淡出；支持单步撤销；无选区时淡变自动作用于开头/结尾 1 秒
- **导出**：16-bit PCM WAV（单/双声道，保持原采样率），自动触发下载
- **播放**：空格播放/暂停、Home 回开头；选区内播放；播放时播放头自动滚动
- **异常提示**：解码失败、空文件、文件过大、无选区、Worker 不可用（自动降级主线程）等均有 toast 提示
- **性能**：
  - 峰值计算、编辑、WAV 编码全部在 **Web Worker** 中执行，大文件不卡 UI
  - 大数据通过 `Transferable` 零拷贝传递
  - 波形静态层（标尺/波形/选区）离屏缓存，播放时每帧只 blit + 画播放头，开销与采样数无关

## 操作

| 操作 | 方式 |
| --- | --- |
| 打开文件 | 点击「打开」或拖入页面（WAV/MP3/M4A/OGG/FLAC 等浏览器可解码格式） |
| 缩放 | 鼠标滚轮（上下滚动）/ 触控板捏合 |
| 平移 | Shift + 滚轮，或水平滚动 |
| 框选 | 在波形区域拖拽；点击边缘把手可调整选区；双击清除 |
| 播放/暂停 | 空格 或 播放按钮（有选区时播放选区） |
| 撤销 | Ctrl/Cmd + Z |
| 导出 | 「导出 WAV」 |

## 运行

Worker 不能通过 `file://` 加载，请用任意静态服务器：

```bash
# 任选其一
python3 -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080/`。Worker 创建失败时会自动降级为异步主线程计算并弹出提示。

```
js/app.js           主控：UI 接线、编辑/导出流程、toast 异常提示
test/               Node 测试（34 个用例，无需浏览器）
```

## 实现说明

- **波形准确性**：基础块 64 采样，逐级 64 倍聚合；绘制时选「每像素采样数」最接近且不超过的级别，保证任何缩放比例下只多画块、不丢峰；末尾不足整块仍输出真实 min/max。
- **编辑正确性**：所有编辑基于采样帧精确切分/拼接；编辑后重建 `AudioBuffer` 与峰值金字塔；撤销保存上一状态的 PCM + 金字塔深拷贝。
- **导出正确性**：标准 44 字节头交错 PCM；超 ±1 样本安全削波；测试中对导出文件做解码往返校验。
- **异常**：所有 Worker/解码/文件异常都会 reject 到 UI 层并显示 toast；编辑/导出期间按钮锁定，防止并发操作。
