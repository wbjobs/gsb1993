# 波形音频编辑器

基于 Web Audio API、Canvas 和 Web Worker 的零依赖音频编辑示例。

## 功能

- 导入常见浏览器可解码音频，支持点击选择和拖拽导入。
- Web Worker 计算波形峰值，Canvas 双层绘制静态波形和播放头。
- 可精确裁剪选区，支持滑块和画布手柄编辑。
- 支持淡入、淡出，二者分别限制在选区长度一半以内，避免包络重叠。
- Web Audio 按当前选区和包络预览播放。
- 导出保留原采样率和声道数的 16-bit PCM WAV。
- Worker 不可用或 Worker 内部返回业务错误时，自动切换到主线程计算并提示。
- 解码失败、空选区、文件过大、导出超限等异常均有状态文本和 Toast 提示。

## 运行

```bash
npm start
```

然后打开 `http://localhost:8080`。也可以点击“载入演示音频”，无需准备素材。

## 测试

```bash
npm test
```

测试覆盖峰值聚合、峰值重采样、渐变帧数约束、边界增益、16-bit PCM 转换、WAV 头、裁剪和立体声交错导出。

## 性能设计

- 波形只保存降采样后的最小值和最大值，而不是逐帧绘制全部采样。
- 初始峰值计算放在 Web Worker，大数组通过 Transferable 交回主线程。
- Canvas 根据 devicePixelRatio 适配，播放期间只重绘透明覆盖层。
- 导出 PCM 按块写入并主动让出事件循环，持续上报进度。
- 窗口变宽超过约 10% 时才重新请求更高精度峰值，避免 resize 风暴。

## 导出说明

导出文件名为 `原文件名-edited.wav`。音频数据先按帧裁剪，再施加与预览一致的线性淡入淡出，最后写入标准 WAV 容器。当前导出格式为 PCM 16-bit，不重新采样。
